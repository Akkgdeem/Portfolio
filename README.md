About This Project

This repository is a research portfolio built as part of a hiring
process with 100Hires. I chose the topic AI-Powered SEO Content
Production because it sits at the intersection of two major shifts
happening right now: the rise of LLM-driven search (ChatGPT, Perplexity,
Google AI Mode) and the need for content teams to scale without
sacrificing quality.

The goal was to find 10 genuine practitioners — not theorists — and
collect their highest-signal content to build a foundation for a
real playbook.
Tools I Used

- Cursor IDE — primary code editor
- Claude Code — AI assistant for research structuring and writing
- Codex — additional AI support
- GitHub — version control and public portfolio hosting
- VS Code — file editing and repository management
